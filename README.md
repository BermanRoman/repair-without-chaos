# Ремонт без хаоса — консультант по ремонту для Claude

Папка-консультант для Claude Code: команда агентов разбирает **ваш** ремонт по материалам бесплатного курса «[Ремонт без хаоса](https://evrasia.bermanshop.ru)».

Курс подготовлен ТЦ «Евразия» (Пермь), автор — Роман Берман, заместитель директора ТЦ. Курс бесплатный, консультант тоже.

## Как начать

Нужны платная подписка Claude (Pro или Max) и приложение Claude для компьютера (Claude Desktop).

1. Откройте Claude Desktop и перейдите на вкладку **Code**.
2. Напишите в чат:

   > Скачай себе репозиторий https://github.com/BermanRoman/repair-without-chaos и подготовь его по README.

3. Claude скопирует консультанта в папку на вашем компьютере и скажет, как её открыть.
4. Откройте новый чат в этой папке и напишите `/start` или просто задайте вопрос о своём ремонте.

## Что умеет

Вы рассказываете о своей квартире и спрашиваете, как у знакомого прораба. Например:

- «Новостройка без отделки, 54 м², с чего начать?»
- «Что раньше: стяжка или штукатурка?»
- «Посчитай плитку в ванную 1,7 × 2,2 м»
- «Вот фото электрики, можно закрывать стены?»
- «Посмотри смету бригады»

Claude ведёт разговор сам и поручает части работы агентам:

| Агент | Что делает |
|---|---|
| Ведущий (прораб) | Держит профиль вашего ремонта, отвечает, решает, кому что поручить |
| Библиотекарь | Находит в курсе нужные уроки, разборы и нормы |
| Сметчик | Считает материалы, запас, бюджет и график по формулам курса |
| Приёмщик | Помогает принять работу или новостройку по фото и чек-листам |
| Договор | Разбирает смету и договор мастера, готовит вопросы |
| Нормы | Проверяет ответы с нормами, законами, расчётами и вопросами безопасности |

Профиль ремонта Claude ведёт в файле `ремонт.md`: тип квартиры, этап, решения, что принято. В следующий раз разговор продолжится с того же места. Фото, сметы и договоры удобно класть в папку `мои-файлы/`. Оба остаются только на вашем компьютере и в Git не попадают.

В папке `knowledge/` лежат тексты курса:

- уроки в порядке ремонта;
- разборы частых вопросов;
- ссылки на чек-листы и калькуляторы на сайте курса;
- реестр сверенных фактов с первоисточниками и оговорками сверки.

Калькуляторы и схемы остаются на сайте, а к каждому ответу Claude даёт ссылку на урок, где тема разобрана подробно.

## Команды

| Команда | Зачем |
|---|---|
| `/start` | Знакомство: 5–7 вопросов о квартире, профиль и личная карта следующих шагов |
| `/inspect` | Принять работу или этап по фото |
| `/estimate` | Посчитать материалы, бюджет, график |
| `/contract` | Разобрать смету или договор мастера |
| `/update` | Скачать новую версию курса из GitHub |

Команды не обязательны: можно просто задавать вопросы о ремонте.

## Важно

Консультант отвечает по курсу и честно говорит, когда в курсе ответа нет. Он не заменяет проектировщика, электрика, газовую службу, управляющую компанию и юриста.

Работы с газом, стояками, этажным щитом, вентканалами и несущими стенами он не учит делать самому. Он говорит, кто их делает и куда звонить.

Нормы и законы меняются. У каждого факта в базе стоит дата сверки, а оговорки сверки перечислены в начале `knowledge/facts.md`. Перед важным решением проверьте действующую редакцию.

Иногда Claude спрашивает разрешение выполнить команду: прочитать документ, пересчитать смету, обновить папку. Это обычный порядок Claude Code. Команды консультанта работают только внутри его папки.

## Для Claude: как подготовить репозиторий

Этот раздел — инструкция для Claude, которого попросили «скачать и подготовить» этот репозиторий.

1. Спросите, куда положить консультанта. По умолчанию — папка `~/Мой ремонт` (в домашней папке).
2. Скопируйте репозиторий:
   - есть Git — `git clone https://github.com/BermanRoman/repair-without-chaos.git "<папка>"`;
   - Git нет или macOS предлагает установить инструменты разработчика, а человек не хочет — скачайте архив `curl -L -o /tmp/rwc.zip https://github.com/BermanRoman/repair-without-chaos/archive/refs/heads/main.zip`, распакуйте `unzip` и перенесите содержимое `repair-without-chaos-main/` в выбранную папку. Обновлять такую копию придётся новым архивом.
3. Проверьте, что в папке есть `CLAUDE.md`, `.claude/agents/`, `.claude/skills/` и `knowledge/index.md`.
4. Агенты и команды подключаются, когда эта папка открыта как рабочая. Если вы можете сменить рабочую папку сессии — смените. Если нет — объясните человеку: «Нажмите новый чат на вкладке Code, выберите папку `<папка>` и напишите `/start`».
5. Если человек хочет продолжить прямо здесь, прочитайте `<папка>/CLAUDE.md` и работайте по нему. Пути в нём отсчитываются от `<папка>`. Агентов в этом случае заменяйте подагентами общего назначения, передавая им текст файла агента.

## Как устроен репозиторий

```
CLAUDE.md            ведущий: правила ответа и кому что поручать
.claude/agents/      агенты: библиотекарь, сметчик, приёмщик, договор, нормы
.claude/skills/      команды /start, /inspect, /estimate, /contract, /update
knowledge/           база курса (выгружается с сайта, руками не править)
templates/           шаблон профиля ремонт.md
docs/                заметки для автора
```
