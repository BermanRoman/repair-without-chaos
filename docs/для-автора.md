# Заметки для автора репозитория

- `knowledge/` руками не править. Её целиком пересоздаёт выгрузка из исходников курса — тех же, из которых собирается сайт evrasia.bermanshop.ru. Выгрузка вырезает разделы о ТЦ и о самом консультанте, превращает метки инструментов в ссылки, чистит служебные пометки в реестре фактов. Если проверки не прошли, рабочая папка `knowledge/` остаётся нетронутой.
- После новой выгрузки — коммит с описанием, что изменилось в курсе; люди получают обновление командой `/obnovit`.
- ТЦ «Евразия» упоминается только в README.
- Агенты — `.claude/agents/rbh-*.md`, команды — `.claude/skills/*/SKILL.md`, правила ведущего — `CLAUDE.md`. Пути — от корня репозитория.
- Числа уроков и разборов в README не указывать: они меняются с каждой выгрузкой, точные — в `knowledge/index.md`.
